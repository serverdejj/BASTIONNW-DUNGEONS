# BASTION DUNGEONS - Modos de edición OP

## Comandos nuevos
- `/dungeon romper`: activa o desactiva poder romper bloques dentro de los mundos de Dungeons. Solo OP, por jugador.
- `/dungeon libre`: activa o desactiva el límite de 33 bloques horizontales y de altura solo para ese OP.

Se activan o desactivan al repetir el comando. No permiten colocar bloques ni quitar otras protecciones. No cambian la protección de otros jugadores. Fuera de las mazmorras no modifican nada. Al desconectarse se desactivan.

**ATENCIÓN:** Los cambios que se hagan a una instancia de mazmorra no se transfieren automáticamente al archivo `.schem` original. Para conservar modificaciones permanentes, edita y vuelve a guardar el schematic.

Los mensajes son editables en `messages.yml` (si ya existe un archivo personalizado en el host, copia las seis claves `admin-*` nuevas).
