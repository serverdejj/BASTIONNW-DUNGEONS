# Inicio manual de mapas por OP

- `/dungeon map` lista mapas `.schem` de la carpeta del plugin.
- `/dungeon map dungeon1-endlessxl facil`
- `/dungeon map the-labyrinth normal`
- `/dungeon map netherybreis dificil`
- TAB completa los mapas y las dificultades. No abre la votación.
- El líder del equipo debe usar el comando.
- `/dungeon go map <mapa>` sigue funcionando como antes con NORMAL.
- `/dungeon go map <mapa> <dificultad>` también acepta dificultad opcional.
- La ruleta conserva su sistema y su configuración independiente.
