# Prueba experimental Bedrock
Requiere Floodgate y LibsDisguises activos en Survival. No crea entidades nuevas. Aplica un disfraz ENDER_DRAGON exclusivamente a jugadores reconocidos por Floodgate, sin modificar la hitbox del servidor. El cliente Geyser puede no representar correctamente la entidad o sus interacciones: verificar en una dungeon de prueba. No modifica el resource pack Java ni repara sus modelos ModelEngine. Config existente: netherybreis.dragon.bedrock-fallback.enabled (por defecto true). Desactivar y reiniciar si falla. Revisar consola por mensajes Dragon Bedrock. Compilar con GitHub Actions.
